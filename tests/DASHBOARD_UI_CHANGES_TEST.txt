TOPICS API - SHEET CREATION FIX
===============================

SUMMARY OF CHANGES
------------------
Fixed the issue where adding a topic would fail if the user's Google Sheet 
didn't exist yet. Now the API will:
1. Attempt to add the topic to the existing sheet
2. If the sheet doesn't exist, create a new sheet with headers
3. Sync all existing subjects from article_styles to the new sheet
4. Add the new topic
